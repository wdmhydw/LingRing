# 0.6.2 本地试用版

修复同一圆环中有的目录显示图标、有的没有，名称字号和位置不一致的问题。

- 删除按扇区空间选择图标及 12.5 / 11.5 / 10.5 字号的分支。全部目录采用纯文字、统一字号和字重；中心当前目录及引导图示同步。
- 短名称按实际文字居中，长名称在统一字号下选择一行或两行，超长时省略并保留悬停全名提示。
- 修复空白行距、字体边距和 WPF 二次自动换行造成的过早省略；四角窄扇区先利用外侧空间，避免两个字也只剩省略号。
- 完整圆、四边半圆、四角局部圆及 1–4 项均分布局使用同一套排版规则。保留蓝灰配色、圆角、蓝弧和进退动效。

从托盘退出旧版，再运行 0.6.2 便携版或安装新版本。默认起点与常用排序保留；F1 可重看更新后的引导。

此版本为 Windows x64 本机试用，未签名、未上传公开 Release。验收范围和构建信息见 [验收记录](ACCEPTANCE_LOG.md) 及归档内 manifest。
