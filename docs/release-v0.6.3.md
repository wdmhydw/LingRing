# 灵环·文件快速整理 v0.6.3

本版升级圆环导航、目录排版和动效，修复边角空白过大及快速滚动时文字突然出现的问题。

## 更新内容

- 第三圈及更深目录采用蓝弧进入：停在名称上只阅读，从内容区移向外缘深蓝弧线才进入下一层；稍移出蓝弧再移回即可继续，静止时不会连续下钻。
- 圆心保持在中键点按位置。每圈根据自己的半径和屏幕边界展开，利用左侧、下方等剩余空间；展开外圈时内圈不重排。
- 每圈按实际数量分布：三项三等分、两项二等分、单项占满可用圆环或弧面。
- 目录统一使用纯文字、相同字号与字重，保持圆角和蓝灰配色。长名称停留约 550 毫秒可查看全名和路径。
- 修复异步读取、缓存立即返回打断滚轮动画的问题。连续滚动逐段衔接，动画期间名称保持水平，完整圆环的新旧名称在转动中平滑交接。
- 新手引导、使用说明与 README 同步更新。公开截图使用打码演示目录，不包含真实文件名和本地路径。

## 下载与升级

- 安装版：`LingRing-0.6.3-windows-x64-setup.exe`
- 便携版：`LingRing-0.6.3-windows-x64-portable.zip`
- 校验值：`SHA256SUMS.txt`
- 构建信息：`release-manifest.json`

[GitHub 下载](https://github.com/wdmhydw/LingRing/releases/tag/v0.6.3)

升级前先从托盘退出旧版，再安装或解压新版。原有默认起点与常用排序会保留；从托盘“新手引导”或轮盘中的 F1 可重看操作说明。

## 兼容性与验证

- Windows 10 / Windows 11 x64，自包含运行时，无需另装 .NET，也无需激活码。
- 本版未做代码签名；没有 macOS 产物。
- 194 项自动化测试；安装器隔离解包与便携程序一致，并检查包内原生界面与滚动中间帧。真实安装、原地升级和卸载未纳入本次自动化回归。
- 安装版、便携版和两端下载回读的校验结果记录在发行验收中。

左键点击扇区会直接移动文件；点击蓝弧只导航。首次体验可先使用托盘“安全演示”。
