# 灵环·文件快速整理：架构与安全说明

## 当前架构

正式运行入口是 `GongSiOrganizer.RadialPrototype`。它是一个独立的 WPF 托盘程序，不会把托管代码注入资源管理器进程，也不会注册右键 Shell 扩展。

主要组件如下：

- `RawMouseInputListener`：通过 Windows Raw Input 接收鼠标按键通知。监听是观察式的，不拦截或吞掉原应用收到的鼠标事件。
- `ShellMiddleClickScope`：检查鼠标下窗口的所属进程和窗口类，只允许 Windows 桌面及文件资源管理器文件列表区域继续处理。
- `FileTargetResolver`：在允许的区域中解析鼠标下项目及资源管理器当前多选集合。
- `DirectoryTreeCache`：建立“此电脑”及本地磁盘入口，目录在悬停时异步按需读取；用户选择的文件夹只作为默认展开起点。
- `DirectoryChildrenCache`：保存已经访问过的一级子目录结果，使用 LRU、两分钟有效期和自适应内存上限，避免全盘扫描和 UI 线程磁盘访问。
- `RadialOverlayWindow` / `RadialMenuControl`：绘制同心圆目录轮盘并处理悬停、滚轮、返回和确认操作。
- `DirectMoveBatchService`：在程序自身进程内执行批量直接移动、重名自动编号和路径安全检查。
- `TrayIconService` / `TrayMenuWindow`：管理轮盘默认起点、引导、目录刷新、常用排序、提示和监听开关。

## 中键处理边界

收到中键通知后，程序按以下顺序处理：

1. 获取鼠标位置、鼠标下窗口以及根窗口。
2. 要求根窗口属于 `explorer.exe`。
3. 要求窗口祖先链包含 `SHELLDLL_DefView` 或 `SysListView32`，即桌面或文件列表视图。
4. 只有通过检查后才解析文件目标并显示轮盘。

因此浏览器、聊天软件、任务栏、资源管理器工具栏，以及其他应用内的系统文件选择框都不会触发轮盘。任何识别异常都会保守地拒绝处理，不会扩大监听范围。

## 目录读取与性能

- 第一圈只显示已就绪的本地固定盘和可移动盘；进入某个扇区时才在线程池读取它的直接子目录，不递归扫描整块磁盘。
- 如果设置了默认文件夹，轮盘打开时只沿该文件夹的祖先链按需读取并预选；读取较慢时会立即退回“此电脑”入口，后台结果可供下次使用。
- 目录读取最多两路并发，避免机械硬盘和可移动设备发生并发寻道；读取较慢时轮盘继续响应并显示加载状态。
- 共享缓存按系统可用内存自动选择约 4、8、16 或 24 MB 上限，同时限制缓存父目录数量为 256–1024 个。超大单目录只在当前轮盘会话中临时保留。
- 可以从托盘手动刷新整个目录缓存，程序自身的新建和移动操作也会主动更新目录。
- 不在资源管理器进程内枚举目录或执行文件移动，因此归档目录较大时不会把资源管理器拖入长时间操作。
- 每一层目录独立分页显示，滚轮只切换鼠标当前所在层级；第三圈使用“内容辨认 → 蓝弧短停进入”，每次换层必须有新的移出、移回动作；慢速亚像素移动和动画期间的手势均保留，静止不会连续进入。各圈按实际目录数量均分，绘制、命中与蓝弧共用同一组角度。

## 移动语义

- 文件和文件夹都执行直接移动，不创建副本。
- 本地目录统一使用内部磁盘令牌，确认时重新解析并验证真实路径；虚拟的“此电脑”本身不能作为目标，离线磁盘、网络映射盘和越界路径都会被拒绝。
- 默认起点不是安全边界：用户可以右键逐级返回它的父目录、磁盘和“此电脑”，再选择其他本地磁盘。
- 目标存在同名项目时生成 `名称 (1)` 一类的可用名称，绝不覆盖。
- 禁止把文件夹移动到它自己或它的子目录。
- 跨磁盘移动文件夹时逐项搬移；只有已经清空的源目录才会被移除。
- 一次批量移动会完整处理选择集合，并汇总成功和失败结果。
- 左键确认后不提供第二次确认，也不接入资源管理器撤销队列。

## 本地数据与隐私

程序不联网，不依赖模型 API，也不上传文件名、目录结构或使用记录。

本地仅保存：

- 最高层归档范围、轮盘默认起点和引导状态；
- 各目标目录的选择次数与最近使用时间；
- 用户选择的提示和监听开关。

数据优先写入当前用户的 `LocalAppData\GongSiOrganizer.RadialPrototype`。如果该位置不可写，会依次尝试 `AppData`、程序目录下的 `data` 和临时目录。不会读取旧版曾使用的 `ai-key.bin`。

## 旧项目说明

仓库中保留的 `GongSiOrganizer.ShellExtension` 与 `GongSiOrganizer.App` 是早期右键菜单方案的历史代码，便于测试和追溯；当前安装脚本不会发布、注册或启动这些组件。请不要手动启用旧 Shell 扩展。
