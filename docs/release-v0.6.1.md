# 0.6.1 本地试用版

修正 0.6.0 改动过大的布局和蓝弧重入手感。

- 移除上下横条和常驻右侧卡片。圆心恢复为中键点按位置，边缘自动显示半圆，角落显示四分之一圆。
- 每一圈按实际目录数铺满：3 个三等分、2 个二等分、1 个完整无接缝圆环。局部圆环同样均分可用弧面；绘制、鼠标命中、蓝弧保持一致。
- 修复高 DPI 下慢速小幅移动不被识别、动画期间手势丢失。稍移出蓝弧再移回即可继续，向内、绕端点及向外短距离离开均可；鼠标静止仍不会连续进入。
- 长名称停留约 550 ms 后显示完整名称提示，移开即收起。窄扇区优先名称，按圆角实际几何约束文字及图标。
- 修正引导中双行文字压到内弧的问题；更新使用说明和升级引导，F1 可重看教程。

保留原有蓝灰配色、相切圆角、分圈打开、蓝弧呼吸及进退交接动效。点击蓝弧不移动文件，点击目录主体仍直接移动。

从托盘退出旧版，再运行 0.6.1 便携版或安装新版本。原有默认起点与常用排序保留。此次为 Windows x64 本机试用，未签名、未上传公开 Release。验收范围及构建信息见 [验收记录](ACCEPTANCE_LOG.md) 和归档内 manifest。
