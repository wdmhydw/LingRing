# 文件快速归档 v0.5.5

## 本版更新

- 目录改为统一层级：“此电脑 → 本地磁盘 → 文件夹”。轮盘第一圈显示当前已就绪的本地固定盘和可移动盘，可跨 C:、D:、E: 等磁盘选择目标。
- 任意本地文件夹都可以设为轮盘默认起点；右键可以继续退回它的父目录、磁盘和“此电脑”，不再把“指定文件夹”与“此电脑”作为两个并列模式。
- 从默认文件夹打开时只显示它的子目录，更高层级会保持隐藏，直到用户主动右键返回。
- 滚轮浏览与进入下一级分离：前两圈仍即时预览下级内容，第三圈滚动只切换同级目标；普通悬停约 450 毫秒、滚轮停止约 850 毫秒后才进入，连续滚动会重新计时。
- 悬停高亮不再移动扇区；只有真正出现或更换下级目录圈时播放展开动画，叶子目录的选中变化不会再引起轮盘缩放。
- 目录改为异步按需读取。磁盘枚举不进入 UI 线程，慢速磁盘读取期间仍可返回或取消。
- 使用自适应有界缓存：根据系统可用内存选择约 4、8、16 或 24 MB 上限，最多两路磁盘读取并发，不进行启动时全盘扫描。
- 旧版保存的固定归档根目录会自动迁移为默认起点，原有常用排序同步补全磁盘和祖先路径。
- 完善跨磁盘移动：单文件和文件夹都保持移动语义，目标完整写入后移除源项目；重名时仍自动编号且不会覆盖。
- 新手引导、托盘菜单和归档范围选择窗口同步更新。

## 兼容性

- Windows 10 / Windows 11 x64。
- 安装版和便携版均为自包含程序，无需另装 .NET Runtime。
- 不要求安装 Everything、Listary 或 Windows Search。
- 网络映射盘默认不列入目录轮盘，避免网络延迟影响响应。
