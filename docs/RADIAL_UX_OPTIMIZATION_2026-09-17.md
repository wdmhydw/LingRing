# 灵环轮盘：可读性、深层导航与动效优化方案

日期：2026-09-17。源码基线：`main@945902c67aa46737363aa4beafaaad9a19ba61ff`，开始时工作区干净。产品源码版本：0.5.5。

最新阶段：用户随后批准制作成品；WPF 0.6.0 已实现本文主方案，验收见 [ACCEPTANCE_LOG](ACCEPTANCE_LOG.md)，产品动效以 [MOTION_SPEC](design/MOTION_SPEC.md) 的 WPF 参数为准。下面的根因与对比保留设计阶段语境。

## 1. 建议采用的方向

保留同心圆、每圈最多四项、所在圈滚轮切换，以及“左键移动、右键返回”的已有操作。当前方案按用户最新要求改为：**第三级开始，普通悬停只阅读；从内容区移向扇区外缘的深蓝弧线，才进入下一层。** 蓝线占当前扇区外弧约三分之一，轻微呼吸；取消鼠标点击展开路径。

核心改动：

1. 菜单整体在屏幕内安置，中心与文字完整可见；取消默认把四项挤进四分之一圆的策略。
2. 扇区使用两行识别标签，旁边提供可停留、可展开的完整名称卡。分别处理目标文件夹名与源文件名。
3. 阅读与导航按空间区分。蓝弧有宽于笔画的命中区，移开取消；点击蓝弧不执行移动。换层后必须回到新内容区，才能再次经过蓝弧进入。
4. 动画分为打开、聚焦、展开、深层切换、返回和关闭；父级位置稳定，新内容有来处，旧内容有去处。

当前交互样稿：[蓝弧进入](design/radial-interaction-preview.html)。[动效与手势规格](design/MOTION_SPEC.md)记录本次参数、边界与验证。使用虚构目录和文件名，只模拟导航和反馈，无文件系统访问。

旧 [A 中键版](design/radial-middle-click.html)与 [B 分段悬停版](design/radial-hover-dwell.html)保留为历史比较，不再是当前实施方案，也不再跟随新入口同步生成。

## 2. 证据与根因

| 现象 | 本轮复核到的实现 | 影响 |
| --- | --- | --- |
| 边角像几块阶梯，中心内容不完整 | `RadialLayout.Create` 保持点击点为中心；`ChooseArc` 在边角返回 90°；完整中心圆的理想边界最终与工作区求交 | 四个扇区仅各 22.5°，标签容易拥挤；中心圆靠边时存在被窗口截断的路径 |
| 名称难以区分 | `DrawWedge` 的标签宽度受径向厚度限制，字号 10.1 DIP；`DrawCenteredText` 默认只有一行且尾部省略 | 相同前缀的目录容易看起来完全一样；中心标题也会省略 |
| 缺少路径上下文 | `RadialMenuSession.Breadcrumb` 已生成路径，但轮盘绘制没有使用它 | 深层替换后不容易辨认所在层级 |
| 读名字时进入下一级 | 普通悬停 450 ms、滚轮后 850 ms 都通往 `session.Hover`；第三圈非空目录会改变第二、第三圈的内容来源 | 阅读与导航共用同一触发条件，延长一点仍会误入 |
| 已有防连跳仍不够 | 第三圈展开后 `_suppressDeepDrill` 暂时抑制继续进入；指针移动 12 DIP 即解除 | 已有保护，但小幅移动也可重新开始计时；保护不等于阅读模式 |
| 下一级突然出现 | 非滚轮过渡为 210 ms，主要把新圈从 0.975 缩放到 1，直接以不透明状态绘制；滚轮为 290 ms | 新目录和旧目录缺少连续的交接，整体缩放难以说明导航方向 |
| 显得像一叠半透明块 | 现有填充使用 alpha 合成、较明显白边，每个扇区各画阴影；打开时整体 0.92→1 | 桌面文字可能透入，扇区边界抢眼，中心操作文案过密；没有证据表明当前有背景模糊 |

证据等级：以上源码行为为 `verified_current`。截图可见文字干扰和形态拥挤，但单张裁剪图不能单独证明操作系统越屏；越屏判断来自布局代码。没有复现用户本机运行过程，不能据此断言全部“偶发奇怪显示”只有一个根因。高 DPI、异步结果回流、动画中点击需纳入实现后的复现矩阵。

`PROJECT_HANDOFF.md` 的旧验收、旧参数及历史偏好属于 `handoff_claim`，不构成新的用户指令。用户此次明确选择“内容区 → 特定蓝弧”的导航手势，优先于旧文档中的交互偏好；不是任意向外划动都展开。

## 3. 布局与视觉

### 3.1 完整轮盘优先，空间不足有明确降级

- 开启前一次性测量轮盘、阴影、路径条和名称卡的联合边界；以当前显示器 work area 与 DPI 为准，保留 16 DIP 安全边距。
- 首选完整圆，必要时将整个菜单向屏幕内部平移。只在打开前确定位置，悬停和异步目录返回时不追着鼠标移动，也不挪动系统指针。
- 若开口位置与点击点分离，用一次性的细小定位标记帮助理解；不画持续闪烁的引导线。开启事件不能直接命中并执行新位置下的选项，需后续真实指针输入。
- 标准初值：中心半径 50 DIP、圈宽 70 DIP、圈间距 4 DIP，三圈直径约 544 DIP。它是试验参数，不是已验收尺寸。
- 联合边界放不下时，依次尝试名称卡换边/上下停靠、两圈紧凑视图（祖先变为路径条）、单圈配目录列表。模式在一次开启中保持稳定。深度不减少，只减少同时展示的祖先圈。
- 不用整体缩小字体或裁掉中心解决空间不足。低分辨率与高 DPI 场景必须进入紧凑模式。
- 同级项目数量与扇区角度在当前层稳定；一到三项时不临时撑满并旋转整圈。缺项不画假的可点击文件夹，使用连续底盘维持轮廓。

这是有意调整原来的“点击点必须等于圆心”：完整内容和稳定命中优先。必须在屏幕四角实测新增鼠标行程，不能只看中心截图。

### 3.2 收敛视觉层级

采用浅色雾面底盘、细分隔线、统一 Windows 文件夹图标与单一蓝色焦点。中心只保留目标、移动动作和简短源数量；返回/取消移到轮盘外的固定提示条。

| 元素 | 设计初值 |
| --- | --- |
| 主表面 | 接近实色的暖白/冷白，建议不透明度 94%–98%；高对比模式纯色 |
| 文本 | 主色 `#202B3A`，次色 `#536174`；必须在实际合成背景上检查对比度 |
| 焦点 | 淡蓝填充 + 1–1.5 DIP 蓝色轮廓，不靠颜色单独表达层级 |
| 扇区标签 | 12.5–13 DIP、最多两行；不因名称长而缩小字号 |
| 完整名称卡 | 320–360 DIP 宽、主标题 14 DIP、正文 12–13 DIP |
| 图标 | 20–24 DIP，与标签分区，图标和文字不随扇区旋转 |
| 阴影 | 整体一层柔和阴影；名称卡一层；避免每个格子各叠一层重阴影 |

### 3.3 圆角修订（本轮重点）

上一版样稿的圆弧与直线直接相交，四个连接点实际为尖角。现在每块扇区的外侧两个角、内侧两个角都使用与直线/圆弧相切的小圆弧连接，焦点轮廓同步采用同样的圆角。

- 标准圆角初值 10–12 DIP，样稿使用 11；圈间空隙约 10 DIP、切向分隔约 6 DIP。实际 WPF 需结合总体尺寸复核。
- 内外半径或角度变化时动态限制圆角半径，保证四角不互相侵入，尤其覆盖 22.5° 的窄扇区；不靠圆角描边伪装尖角填充。
- 分隔使用留白和低对比轮廓，不保留尖锐交叉线；圆角后的视觉轮廓与点击命中共用同一几何。
- 标签安全内框重新检查，避免圆角切掉文字；降低底盘与分隔线的对比，让圆角自然显现。

真实磨砂不是首期依赖：先用足够不透明的底色消除桌面文字干扰，再依据 WPF 原型的合成开销评估系统材质。没有性能证据前不引入大面积动态模糊。

## 4. 长名称：速读与完整阅读各有位置

目标目录名称和正在移动的源文件名称分开处理，不能只修扇区上的文件夹标签。

1. **扇区速读**：优先两行显示；测量实际字体宽度，在词/标点边界换行。两行文本必须整体落在扇区安全内框，左右朝向的扇区按径向厚度限制宽度，不能只按弧长放宽。仍放不下时中间省略，保留前缀与有辨识度的尾部。文件标签保留扩展名；目录不人为添加扩展名。样稿中的短标签为人工准备的虚构示例，不代表已实现通用名称提取算法。
2. **完整阅读**：稳定悬停 160–200 ms 后在固定名称卡显示全名和完整路径；名称卡不会随鼠标抖动。切换候选只交叉淡化内容，不改变卡片位置。
3. **极长名称**：卡片默认展开两到三行，提供“展开全名 / 查看完整路径”；展开后允许换行、滚动和文本选择，不再次硬截断。离开扇区进入卡片时保留同一候选，卡片本身属于菜单命中区域。
4. **相似名称**：同级存在相同前缀时保留区别段，如 `…2026年09月_终稿` 与 `…2026年09月_修订稿`。缩写只参与显示，命中和移动始终绑定完整节点标识。
5. **源文件**：单文件显示名称与类型，长名也能展开；多选显示“待移动 N 项”，点击数量展开可滚动清单。路径内容留在本机，不写入默认诊断日志。
6. **不使用跑马灯**：阅读不应追逐文字，动画也不应与名称识别竞争注意力。

例如：`华东区域_2026年第三季度品牌推广执行方案_客户终审修订版.pptx`，扇区可显示“华东区域… / 客户终审修订版.pptx”，卡片提供完整原名。具体断行需按字号实测，不能简单按字符数截取；中文、组合字符、emoji 均需覆盖。

**沿弧排字已做实际对照，默认不采用。** [沿弧效果](design/radial-interaction-preview.html?labels=arc)在顶部有装饰性，但左右两侧成为斜竖排，字符方向不断变化；底部虽能反转路径保持正向，仍不能统一四个方向的阅读姿态。实验采用 12 px、半径 240、70° 路径，按实际宽度作中间省略，长名依然不能全部放下。当前默认保留横排两行与固定全名卡，实验可由样稿页脚进入。此结论是视觉评估，不是用户阅读速度的实测结论。

## 5. 导航：从内容区移向蓝弧

### 5.1 行为约定

“深层”按**是否需要重排当前可见层级**判断：当前三圈模型即第三圈及更深；紧凑两圈模型应在最外活动圈应用同样规则，不能只写死文件系统绝对深度。

| 输入/状态 | 当前响应 |
| --- | --- |
| 进入任意扇区 | 80–110 ms 内给出填充/轮廓反馈；不平移或缩放扇区 |
| 停留 160–200 ms | 展示完整名称卡；原地可以一直阅读，没有进入倒计时 |
| 第一、第二圈稳定悬停 | 约 550 ms 后只在空出的外圈预览子目录；既有父圈位置不变 |
| 第三圈/需重排的活动圈悬停 | 只阅读；含子目录的焦点扇区显示一段深蓝弧线 |
| 深层进入 | 先经过内容区，再移向蓝弧；约 110 ms 防掠过缓冲后进入一层 |
| 蓝弧处按下/点击 | 取消待进入动作、消耗本次点击，不落到移动命令 |
| 点击扇区主体或中心“移动到此处” | 延续直接移动语义；目标必须与当前展示的名称一致 |
| `Ctrl + 左键` 点击主体/中心 | 产品实现延续新建子目录操作，不复用导航输入；样稿未连接新建操作 |
| 滚轮 | 只换所在圈的同级项；连续滚动只更新候选，不自动进入深层 |
| 滚轮停止 | 新内容保持重入锁；先返回内容区，再移向蓝弧，不原地自动进入 |
| 右键 / `Backspace` | 返回一层；恢复上一层的滚动位置、选中项和可读名称 |
| `Esc` / 菜单外空白 | 关闭；名称卡、路径条、连接走廊不算空白 |

### 5.2 蓝弧位置与防误触

蓝弧沿当前扇区外边缘，位于沿圆周方向的起始三分之一。四个扇区遵循同一位置规则；顶部表现为用户截图里的左上段。样稿外圈半径 258 SVG 单位，蓝弧半径 256，相对扇区中心角为 −40° 到 −12°，覆盖 28°，约为当前外弧的三分之一。

- 视觉笔画 3.6，深蓝 `#204E91`，圆头；透明命中笔画宽 20。WPF 落地以 DIP 重测，不能直接把浏览器缩放后的 CSS 像素当成 DIP。
- 只有焦点扇区的蓝弧显示并呼吸，叶子目录不显示。蓝弧保持可见，不因等待阅读而超时消失。
- 先在该扇区内容区建立导航候选，再移到蓝弧。由圆盘外部直接撞到蓝弧不进入；非蓝弧位置向外划动也不进入。
- 蓝弧内约 110 ms 只用于过滤快速擦过。鼠标离开、换候选、滚轮、按键/点击、返回、关闭及页面隐藏都能取消；不把它做成长时间的进入倒计时。
- 蓝弧内的点击、从蓝弧按下后产生的点击不调用移动动作；按住鼠标经过蓝弧也不进入。
- 进入/返回/滚轮换项后重入锁生效。新内容出现在静止指针下不算意图；必须通过真实鼠标移动回到新扇区的内容区，再进入蓝弧。沿弧轻微晃动不能解锁。

键盘替代保留 Tab 聚焦、方向键换候选、目录项 Enter 进入；中心 Enter 用于移动。重复按键不排队。中键不再用于深层展开。全名卡说明“正在查看”，中心另标明已经选定的移动位置，普通悬停不替换中心目标。

### 5.3 小动画引导

首次打开时，用约 2.5 秒的示范指针演示“停在名称上 → 移向蓝弧”，配两句短提示。引导有自己的视觉层，不派发鼠标事件，不更改用户目录、选择项或移动目标。真实指针输入立即终止示范；右上角“操作引导”可重播。减少动态效果时只显示静态步骤。

### 5.4 防连跳与异步一致性

状态：`Reading → BodyReady → ArcPending → Transitioning → ReentryLocked → BodyReady`。浅层读取可以产生 `PreviewReady`，不等同于深层进入请求。

- 阅读候选 `PreviewNode`、已进入路径 `NavigationPath`、移动目标 `MoveTarget` 分开保存。
- 蓝弧触发或键盘激活时，固定节点 ID、完整路径和导航 generation；预取结果只填充数据，不能单独推进路径。
- 动画期间不累计进入请求。新内容就位后，必须重新经过内容区与蓝弧，或接受新的键盘激活。单纯达到一个指针位移阈值不再作为继续下钻许可。
- 动画中点击移动：不排队、不在动画结束后重放；移动按钮短暂禁用。Esc/返回始终可取消，旧异步响应不能重新打开已关闭的层。
- 鼠标移往已展开子圈时，使用短暂的通行走廊/边界滞后防止扫过兄弟目录导致切换；离开走廊或明确停到新项立即重新判定。它只保护路径，不触发进入。
- 叶子目录无蓝弧；“正在读取”与“无子目录”是不同状态。读取超过约 120 ms 才显示轻量占位，失败提供重试，不能先宣告叶子后突然换层。
- 频次排序冻结至本次菜单关闭，避免名称卡、显示位置与移动目标发生错位。

## 6. 动效编排

参考目标是 Pieoneer 的整体轮廓、焦点清晰度与响应连贯性。已分析用户补充的本地 `Video by martinlexow.mp4`：720×1280、30 fps、425 帧、约 14.17 秒。先每 0.5 秒覆盖全片抽帧，再对悬停与切换片段每两帧细查。视频有镜头缩放与剪辑，不宜把画面里所有移动都解释为软件动画。

| 视频位置（约） | 可观察到的效果 | 应用到灵环 |
| --- | --- | --- |
| 0.67–2.90 秒 | 当前应用图标明显放大，蓝色焦点沿圆周换位，中心显示名称 | 图标可放大 1.06–1.10；焦点作局部响应；名称有稳定阅读位置 |
| 3.70–6.70 秒 | 文件、文件夹的名称出现在中心标签中，外围以图标为主 | 借鉴“图形选择与名称阅读分区”；中文长名与深路径改用容量更大的名称卡 |
| 8.80–9.67 秒 | 四分区控制盘中，高亮块随指针位置呈现轻微偏转/伸出，其余盘面相对稳定 | 试验 1–2 DIP 的焦点装饰层偏移，文字和实际命中区域不跟着走 |
| 10.70–14.10 秒 | 音乐控制使用完整连续底盘，蓝色焦点与下方黑色信息区有明确分工 | 收敛成一个底盘与一个焦点，减少相邻白边和独立阴影 |

这些是视频可见现象，不代表已知 Pieoneer 内部用的是弹簧、几何插值或特定渲染技术。视频没有展示多级目录钻取，也没有一套可分离剪辑影响的完整开/关过程；不能声称已经复刻其层级动画或精确测得其缓动参数。下表数值均为**本项目建议初值**。

| 场景 | 编排 | 建议时长 |
| --- | --- | --- |
| 打开 | 底盘 0.982→1 轻微展开；各圈透明度相隔 22 ms；不为每项排长队 | 总计 280 ms |
| 悬停 | 焦点填充先响应；图标 1.10 放大；文字、底盘和命中区域固定 | 填充 95 ms，图标 160 ms |
| 蓝弧出现与呼吸 | 180 ms 描出圆头细弧；透明度在 0.68–1 之间缓慢往复，小范围底光同步 | 出现 180 ms，呼吸周期 2200 ms |
| 全名卡更新 | 内容交叉淡化，卡片固定；首次出现最多 4 DIP 位移 | 100–140 ms |
| 新子圈出现 | 父圈稳定；子圈从父级外沿约 6–8 DIP 的位移淡入；图标/标签稍后显现 | 220–260 ms |
| 深层进入 | 盘面固定；旧图文向内约 4 单位淡出，新图文从径向偏移 8 单位处就位；四项相隔 16 ms | 旧内容 130 ms，新内容 320 ms，总窗口 368 ms |
| 同级滚轮 | 内容沿切向移动，文字保持正立；快速输入合并到最终位置 | 150–190 ms |
| 返回 | 内容位移方向逆转，恢复原来的选中项；不重播打开动画 | 样稿同为 320 ms，后续可比较更快返回 |
| 关闭 | 迅速淡出；成功移动仍保持已有静默结果策略 | 100–140 ms |

本轮已安装并读取 [motion-web](https://github.com/feitangyuan/motion-web)，采用其最小技术栈、动效分档、持续操作提示、引导与用户状态分离以及可观测验证的做法。样稿主曲线 `cubic-bezier(0.16, 1, 0.3, 1)`，旧内容退出用 `ease-in`，呼吸用 `ease-in-out`；没有为这个局部交互引入 GSAP 或 WebGL。普通悬停、阅读和叶子选择均不让整块扇区弹跳。装饰不侵入相邻圈、不覆盖文字、不改变点击目标。

动画可中断：新事件从当前视觉值继续，旧 generation 完成回调失效。逻辑命中与视觉位置必须一致；正在替换的区域不接受移动动作，不能点到“看见 A、执行 B”。

减少动态效果时取消位移、错峰、缩放、引导指针与呼吸，保留静态深蓝弧和完整手势。当前样稿直接切换，不更改进入的短缓冲。用户明确要求的蓝弧呼吸是唯一持续动效，仅在可见焦点上运行；关闭/隐藏页面时暂停。没有常驻 JS 动画循环，只有播放引导时短暂使用 rAF。

## 8. 验收标准

以下均为计划目标，尚不是实测结果。

| 维度 | 场景与通过标准 |
| --- | --- |
| 屏幕完整性 | 中央、四边、四角；100%/125%/150%/200% DPI；1366×768、1920×1080、多屏负坐标和混合 DPI。联合边界在当前工作区内，文字不裁切，指针命中一致 |
| 文件名识别 | 8/20/60 字中文、120 字英文、相同前缀不同日期/后缀、组合字符与 emoji、极长路径。全名可静止阅读、展开和选择，源与目标不混淆 |
| 深层阅读 | 第 3–8 层内容区停留 3 秒不进入；经过蓝弧进入一次；快速擦过取消；换层后静止或沿弧轻微移动均不连跳 |
| 导航命中 | 从外部直接进弧不展开；先回内容区才可再次导航；弧线按下/点击不移动；主体左键移动到对应目标；动画中点击不延后触发 |
| 圆角几何 | 内外四角与边/弧相切，22.5°/45°/90°、三种半径下无重叠；填充和命中使用同一轮廓；标签不越过圆角安全区 |
| 异步竞态 | 连续选择 A/B、A 的慢请求后返回、关闭后加载完成、目录变叶子、权限失败。旧响应不覆盖新路径，不自动再次钻取 |
| 返回连续性 | 连续进入 5 层并返回，父层滚动位置/选中项恢复；返回不用重看全套打开动画 |
| 材质与阅读 | 浅色、深色、高频文字壁纸；文本对比度实测达到正常正文目标 4.5:1，焦点不只靠颜色 |
| 帧表现 | 指定 Windows 测试机、稳定热缓存、60 Hz 条件下目标 p95 帧间隔 ≤16.7 ms、连续可见卡顿 >33 ms 为 0；记录硬件与测量口径。120 Hz 另记 8.3 ms 预算，不冒充已达成 |
| 动效可用性 | 所有动画途中可 Esc 取消；减少动态效果下完整导航可用；呼吸只作用于可见蓝弧，关闭或隐藏时暂停；引导不更改用户状态 |
| 既有功能 | 中键范围、多选、直接移动不覆盖、Ctrl 新建、所在圈滚轮、右键返回、失败提示均回归 |

建议用相同数据录制旧版与新 WPF 原型各一组真实 60 fps 视频，覆盖长名阅读、三级后连续进入、屏幕左上角、快速滚轮四条路线。邀请 3–5 位实际用户完成同一归档任务，记录误入次数、辨名错误和任务时间；不能仅凭“看起来更顺”验收。
