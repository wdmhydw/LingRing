# 灵环·文件快速整理 v0.7.0

默认沿弧排字、每圈最多 4 项，让长目录名利用圆环空间显示；同时改善中键第一次打开的响应。

- **沿弧排字成为默认**：保留圆环弧度，按扇区空间换行，沿用试用确认的中文、英文和数字方向。
- **随时选择原版**：托盘 → **轮盘显示**，选择沿弧或原版排字；原版同时恢复原有圈宽。
- **每圈数量可调**：支持 2–8 项，默认 4 项，超出的同级目录仍用滚轮切换。数量与排字分别保存，重启继续沿用；数量越多，单项可用空间越小。
- **新手引导补充显示设置**：新增真实轮盘示意；已有用户升级后会看到一次新版引导。
- **改善第一次打开**：提前准备目录和绘制资源，减少首次访问资源管理器选择信息的初始化工作；后续展开仍为 280 ms。

适用于 Windows 10 / Windows 11 x64，自包含，无需另装 .NET Runtime 或激活码。安装版和便携版使用同一份程序；本版沿用未签名发行方式，附件提供 SHA-256。

升级前先从托盘退出旧版，再安装或完整解压便携版。已有轮盘起点和常用排序保留；首次升级默认沿弧排字、每圈 4 项，之后尊重自己保存的显示设置。程序不会自动覆盖正在运行的旧实例。
