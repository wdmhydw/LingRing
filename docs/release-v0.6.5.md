# 灵环·文件快速整理 v0.6.5

修正 v0.6.4 菜单展开过慢的问题，各级菜单恢复利落的响应。

- **各级统一 280 毫秒**：首次打开、二级、三级及更深层从 560 毫秒缩短到 280 毫秒。
- **迅速起步、柔和停稳**：采用 Cubic EaseOut，缩短扇区错峰间隔，保留柔和收尾，去掉慢起步造成的拖沓感。
- **继续由圆心向外展开**：圆环背景与文字同步，已显示的父级保持稳定。
- 保留蓝色等待环、绿色完成、黄色部分完成和红色失败，以及快速滚轮、边角适配和减少动画支持。

升级前从托盘退出旧版，再安装新版本。默认起点、常用排序和文件移动规则沿用现有配置。
