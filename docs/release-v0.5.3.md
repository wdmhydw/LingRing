# 文件快速归档 v0.5.3

这是“文件快速归档”的首个公开发行版。

## 主要功能

- 在 Windows 桌面或文件资源管理器文件区域用鼠标中键打开同心圆目录轮盘。
- 支持文件、文件夹和资源管理器多选项目批量移动。
- 支持逐级悬停展开、分层滚轮切换、右键返回和常用目录优先排序。
- 支持在目标目录上按 `Ctrl + 左键` 即时新建子文件夹。
- 支持自定义归档根目录、托盘管理、新手引导和可选开机自启。

## v0.5.3 修复

- 首次启动不再在新手引导之前额外弹出系统目录选择窗口；归档位置统一在引导内设置。
- 中键监听只响应桌面和文件资源管理器文件列表区域，不再干扰浏览器、聊天软件、任务栏或其他窗口。
- 静默升级时保留用户已有的开机自启选择。

## 安装

推荐下载并运行 `文件快速归档-0.5.3-安装程序.exe`，按安装向导完成设置。也可以下载 `文件快速归档-0.5.3-win-x64-便携版.zip`，解压后直接运行。

如果使用 Listary，请先在 Listary 的“选项 → 集成”中关闭 Desktop 和 File Explorer 的鼠标中键菜单。
