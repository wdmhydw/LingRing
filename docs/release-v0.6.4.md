# 灵环·文件快速整理 v0.6.4

各级菜单统一向外柔和展开，并增加原位置的文件移动结果反馈。

## 更新内容

- 首次中键打开、二级、三级和更深层共用约 0.56 秒的展开节奏。圆环与文字由圆心向外同步展开，缓入缓出，已有父级保持原位。
- 修复后续层级圆环直接出现、文字从外侧向圆心移动的问题；异步目录读取完成也沿用相同过渡。
- 确认移动后轮盘收拢，原位置显示厚蓝色等待环、实心绿色完成、黄色部分完成或红色失败。结果符号与数量为白色；等待环根据真实操作状态显示，不虚构百分比。
- 悬停背景轻微向外响应，文字与点击区域保持稳定，快速切换连续衔接。
- 保留蓝弧进入、滚轮连续切换、边角适配、系统减少动画以及原有目录排序设置。
- 验证脚本使用隔离的通用示例目录并自动清理，避免测试目录进入日常文件搜索。

## 下载与升级

- 安装版：`LingRing-0.6.4-windows-x64-setup.exe`
- 便携版：`LingRing-0.6.4-windows-x64-portable.zip`
- 校验值：`SHA256SUMS.txt`
- 构建信息：`release-manifest.json`

[GitHub 下载](https://github.com/wdmhydw/LingRing/releases/tag/v0.6.4)

升级前先从托盘退出旧版，再安装或解压新版。原有默认起点和常用排序会保留；前两圈停稳展开，第三圈起移向蓝弧进入，Esc 关闭轮盘。

本版沿用 Windows 10 / Windows 11 x64 自包含发行，无需另装 .NET 或激活码；仍未做代码签名，没有 macOS 产物。左键点击目标会直接移动文件，托盘“安全演示”可用于熟悉操作。
