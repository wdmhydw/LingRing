## WPF 0.6.3 产品参数

- 打开：420 ms 总窗口，各圈错开 40 ms；0.88→1 舒展，Cubic EaseOut，稳定后不缩放文字。
- 聚焦：180 ms 填充与边线过渡，扇区命中几何不移动，名称不缩放。
- 深层进入/返回：360 ms，旧内容径向退出 12 DIP，新内容从 18 DIP 就位；返回方向相反。慢目录异步返回也播放交接。
- 同级滚动：240 ms；关闭：130 ms；全名提示：悬停 550 ms 后，180 ms / 5 DIP 淡入。
- 连续滚动：沿用最多三步待处理输入，前一段到位后衔接下一段。动画期间冻结目录快照；异步读取及缓存同步回调不能取消滚轮时钟或队列，最后再衔接新增内容。
- 完整圆环首尾重合处，离开层按 Cubic EaseOut 逐渐淡出，让新名称在转动中接入；局部圆环维持从两端进出及边缘裁剪。正反方向像素回归确认旧名称在结束前消退，避免末帧突然换字。
- 时钟首帧基值为 0，结束为 1；用旋转变换移动缓存扇区，名称反向补偿以保持水平，动画期间不重新测量字形或换行。原生帧检查覆盖首段、队列后续段和静止终态。
- 蓝弧：约占当前扇区外弧三分之一，随目录数量与局部圆环调整，宽 3.8 DIP / 命中宽 20 DIP，呼吸周期 2200 ms；110 ms 进入缓冲。
- 扇区圆角：11 DIP 相切圆弧；布局半径 58–118 / 128–188 / 198–258 DIP。
- 引导：6 秒循环独立图示，不向真实菜单发送事件；窗口 360 ms、翻页 340 ms。
- 托盘/选择起点/新建目录/提示采用 300–320 ms 位移淡入；按钮 180 ms 聚焦和按压响应。
- Windows 关闭动画时保留静态蓝弧及所有触发保护。原生帧测试确认打开前后画面变化，并在完成后稳定。

- 圆心保持中键坐标。每圈按自身外半径与工作区四边交点，选择最大的连续可用弧段，预留 12 DIP 边缘空间；指针本身靠边不足 12 DIP 时不向外扩展。不再按最外圈统一选择 90°/180°。
- 每圈弧段在打开时确定；新增层级不重排已有圈。绘制、文字、命中、滚轮过渡裁剪和蓝弧共用该圈角度。每圈按 1–4 个目录均分；单目录在完整圆时无径向接缝，在局部布局时铺满可用弧面。
- 无上下横条与常驻侧栏；所有目录扇区不画图标，名称统一 Microsoft YaHei UI / SemiBold / 12.5 DIP，行距 18 DIP。中心当前目录与引导目录共用字号和字重。
- 使用实际文字墨迹测量并居中；显式选择一行/两行后不再让 WPF 自动二次换行。狭窄角落按几何向外微调文字锚点，优先保证两字名称可辨，字号不变；真正长名使用省略及完整名称悬停提示。
- 文本缓存包含 DPI，避免复用其他缩放比例的 FormattedText；布局缓存不保存任何按空间切换字号或显示图标的决策。
- 重入：接受亚像素移动；蓝弧命中范围外增加 2 DIP 迟滞，横向绕端点或向外短距离离开也可重新进入。动画期间保留新手势，稳定后经过 110 ms 缓冲只进入一次；静止不解锁。
- 引导采用同样的纯文字目录，保留文字留白与动画裁剪；引导版本仍为 3，0.6.1 用户可按 F1 重看。

## 手势与几何

| 项目 | 样稿值 |
| --- | --- |
| 活动圈内/外半径 | 198 / 258 SVG 单位 |
| 相切圆角 | 11；随宽度和角度限幅 |
| 蓝弧 | 半径 256；相对扇区中线 −40° 至 −12°，28°，约占当前外弧三分之一 |
| 视觉笔画 / 实际命中笔画 | 3.6 / 20，圆头 |
| 内容区重新建立意图 | 当前扇区内部且半径不大于 242，须为换层完成后的新指针移动 |
| 蓝弧短缓冲 | 110 ms，离开即取消，不是阅读倒计时 |
| 点击保护 | 蓝弧按下或点击均不执行移动；按住鼠标经过蓝弧不导航 |

SVG 随容器缩放，以上不是最终 WPF DIP 验收值。只有焦点目录存在子目录时显示蓝弧。叶子不显示；从外部直接进入弧线不触发。导航、返回、滚轮换项都建立重入锁，必须回到内容区再进入；新目录出现在静止指针下不解锁。

状态：`Reading → BodyReady → ArcPending → Transitioning → ReentryLocked → BodyReady`。

## 编排与动效参数

| 事件 | 可见行为 | 时长 / 曲线 |
| --- | --- | --- |
| 开启 | 整盘 0.982→1、淡入，三圈透明度错开 | 280 ms；各圈错开 22 ms |
| 焦点 | 填充先变，图标 1.1 倍，标签保持不动 | 填充 95 ms，图标 160 ms |
| 全名 | 稳定悬停后更新，固定卡片位置 | 等待 180 ms，文字淡入 120 ms |
| 蓝弧显现 | 沿外缘描出一段圆头弧线 | 180 ms |
| 蓝弧呼吸 | 深蓝线透明度 0.68↔1；小范围底光 0.07↔0.18 | 2200 ms，ease-in-out |
| 进入 | 父圈和盘面固定；旧图文内移 4 并淡出，新图文从径向偏移 8 就位 | 退出 130 ms；进入 320 ms，四项错开 16 ms；总窗口 368 ms |
| 返回 | 内容位移方向与进入相反，恢复父目录状态 | 同一组参数 |
| 滚轮 | 仅活动圈替换同级图文 | 190 ms，四项错开 16 ms |
| 关闭 | 即时关闭和取消待处理意图 | 样稿为即时；WPF 可比较 100–140 ms 退出淡化 |

主曲线 `cubic-bezier(.16,1,.3,1)`，图文退出 `ease-in`。视觉层用 CSS / SVG / Web Animations，避免为一个局部动作加入大动效库。没有整体弹跳、动态模糊、变形文字和循环位移动画。

## 首次引导

会话首次打开后演示一次，也可用“操作引导”重播。总时长约 2500 ms：停在名称处约 850 ms → 用 850 ms 移向蓝弧 → 小圆波反馈与淡出。提示为“停在名称上，可以一直读”“移向蓝线，进入下一层”。

示范指针与用户状态独立，不派发输入，不改变目录/选择/移动目标。真实轮盘指针输入、导航、滚轮或关闭会终止引导。背景页面不继续演示。引导是唯一临时 JS 动画循环，结束后释放 rAF。

## 排版取舍

实际制作了 [沿弧实验](radial-interaction-preview.html?labels=arc)与 [交互对照](radial-interaction-preview.html?labels=arc)：半径 240、70° 路径、字号 12，底部路径反向，按实际文字宽度省略。

## 输入与辅助功能

- 鼠标：正文悬停阅读；内容区→蓝弧进入；主体左键模拟移动；右键返回。中键不再展开。
- 键盘：Tab 聚焦，方向键换项，目录 Enter/Space 进入，中心 Enter/Space 模拟移动；Esc 关闭，Backspace 返回。
- 减少动态效果：无呼吸、缩放、位移、错峰或示范指针；保留静态蓝弧、步骤文字和同样的防误入规则。监听系统偏好，允许样稿内显式切换。
- 该工具针对桌面鼠标；窄屏检查证明页面布局不溢出，不代表触摸导航已交付。

## 实现与验证边界

使用 generation 和候选节点绑定取消旧请求。过渡中的图文不接收移动操作；Esc / 返回不排队。预览名称、已进入路径、移动目标分别保存。当前目录数据均为虚构示例，圆环中祖先圈为固定上下文，边缘场景只是避让布局示意。

已通过 33 项浏览器检查，包含实际 CDP 鼠标、滚轮和键盘事件。自由运行时钟下验证了呼吸透明度变化及引导指针位移；15 个加宽命中区采样点全部命中；9 种半径/角度组合验证圆角切除与主体命中；减少动态效果下未残留运行中的动画。结果见检查记录。

测试脚本关闭 Edge 后台节流后执行短时输入：默认无头环境曾把两次鼠标事件间隔拉到约 200 ms，不能拿这种事件间隔判定“110 ms 内快速掠过”的取消行为。修正测试环境后保留事件时间证据，不通过放宽产品阈值掩盖测量问题。

已检查静态、减少动画和沿弧文字的实际截图；未测 WPF 帧率、真实文件移动、DPI、多屏或慢盘异步读取。网页可用性不等于桌面产品发行验收。
