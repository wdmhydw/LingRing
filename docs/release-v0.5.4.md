# 文件快速归档 v0.5.4

## 本次更新

- 移除轮盘获得键盘焦点时由 WPF 自动绘制的黑色虚线外框。
- 保留 `Esc` 取消、`Backspace` 返回上一级等全部键盘操作。
- GitHub README 新增完整轮盘、边角自适应、新手引导和托盘菜单的真实界面图片。
- 新增焦点视觉回归测试；完整测试为 82/82 通过。

## 安装

推荐下载 `FileQuickArchive-0.5.4-Setup.exe` 并按安装向导完成设置。也可以下载 `FileQuickArchive-0.5.4-win-x64-portable.zip`，解压后直接运行。

如果使用 Listary，请先在 Listary 的“选项 → 集成”中关闭 Desktop 和 File Explorer 的鼠标中键菜单。
