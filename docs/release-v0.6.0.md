# 0.6.0 本地试用版

本次将已确认的蓝弧交互接入 Windows WPF 产品。第三圈起，停在名称上只查看；从扇区移到深蓝色外弧才进入下级。蓝弧快速划过取消，点击不移动，进入后必须先回到新内容区，避免连续下钻。

- 相切圆角替代尖角，保留蓝灰 UI 风格。
- 打开分圈舒展、图标聚焦、蓝弧呼吸、进入/返回内容交接，统一托盘、按钮、教程、设置和提示动效。
- 修复慢目录异步返回时直接刷新、跳过内容动画的问题。
- 长名称采用横排两行，保留首尾；完整名称和路径在固定卡片中可阅读、复制。弧形排字经比较未作为默认方案。
- 屏幕边缘整体避让，小空间降为单圈，单圈每一级都使用蓝弧。
- 新手引导加入实际手势动画，0.5.x 升级后提示一次，保留起点和常用排序。

从托盘退出旧版，再安装新包或运行便携版。也可以先启动新程序 `--demo` 体验安全演示；演示不注册全局监听，不移动真实文件。

本包面向 Windows x64，无需另装 .NET。当前为本机试用构建，未签名、未上传公开 Release。macOS 仍需抽离平台服务及原生外壳适配，未生成或验证 Mac 包。

实现与自动化检查见 [验收记录](ACCEPTANCE_LOG.md)。公开发行前仍需真实安装/升级/卸载流程及签名验收；此次安装器按隔离解包后的实际程序进行启动核验。
