# 公开截图规范

README 图片由 `scripts/Capture-PublicScreenshots.ps1` 从当前 WPF 程序采集。

- 使用独立的数据目录和合成文件夹；文件夹名从创建时就是不透明打码占位符，不读取实际业务目录。
- 截图保留真实圆环几何、字号、颜色和交互状态；不重绘 UI，也不改变用户正常使用时的目录名。
- 托盘预览使用“此电脑”起点，不显示本地项目路径。
- 自动截图模式隔离桌面指针输入，避免意外悬停改变预设层级。
- 只提交最终脱敏 PNG。原始测试截图、运行 trace 与构建结果保留在被忽略的 `artifacts/` 或 `Releases/` 下。
- 合成目录和隔离设置放在系统临时目录 `LingRing-QA/<用途>-<随机 ID>/` 中。截图完成或脚本报错后，在 `finally` 中自动清理；临时进程超时也先结束该脚本启动的进程，再清理目录。
- 布局验证使用通用示例名称。测试树不使用真实公司或项目名，避免残留时与用户业务资料混入搜索结果。删除前检查临时目录边界、所有权标记及链接，截图和报告单独保留。
- 早期设计位图与未经脱敏的中间截图不进入本次发布提交；本地开发历史保留。

现有五张图覆盖完整三圈、左下三圈、左下单圈、三项/单项/两项分布，以及托盘菜单。
