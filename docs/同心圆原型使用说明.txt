灵环·文件快速整理 0.6.4 — 各级柔和展开与操作反馈

开始使用
1. 从托盘退出正在运行的旧版，再安装 0.6.4 或解压便携版，运行“灵环·文件快速整理.exe”。无需另装 .NET。
2. 第一次使用或从 0.6.0 及更早版本升级时会显示四步引导。最后一步可选择轮盘默认起点；原有起点和常用排序会保留。从 0.6.1 / 0.6.2 升级可按 F1 重看更新后的图示。
3. 在桌面或资源管理器文件列表中选中文件/文件夹，按鼠标中键。多选时，在其中一个已选项目上按中键。
4. 前两圈：鼠标在扇区停稳约 450 毫秒，展开下一圈。第三圈开始：停在名称上只查看，不会自动进入。
5. 想进入更深目录时，从当前扇区内容区移向外缘的深蓝弧线。蓝弧有轻微呼吸，停留约 110 毫秒便进入；快速划过会取消。
6. 换层后，稍移出蓝弧再移回来即可继续深入，不必大幅退回中心。动画期间的移出、移回会被记住，稳定后只进入一次。鼠标不动不会连续下钻；从外部直接碰到弧线也不会进入。
7. 左键点击目标扇区会直接移动文件。点击中心圆则移动到中心显示的当前路径；悬停中心可核对完整目标路径和待移动文件名。点击蓝弧不会移动文件。
8. 右键或 Backspace 返回上一级；Esc 或点击轮盘外空白关闭。

圆环位置、数量与长名称
- 圆环以中键点按位置为圆心，不再有上下横条或右侧常驻窗口。
- 每圈按自身半径利用屏幕剩余空间，能放完整圆就显示完整圆；靠边时展开到边界附近，保留少量留白。仅在紧贴角落、确实没有空间时接近四分之一圆，不再把所有边角场景固定压成 90°。
- 内圈与外圈各自适应边界，较小的内圈通常能展开得更宽；新增外圈时，已显示的内圈及中键圆心保持原位。
- 首次打开与后续各级统一约 0.56 秒展开，圆环和文字一起由圆心向外缓入缓出；更深层不会突然出现，已有父级保持原位。
- 每圈按实际目录数量铺满可用弧面：3 个三等分，2 个二等分，1 个占整圈；超过 4 个时用滚轮切换同级。
- 所有目录扇区统一为纯文字，不再混用有图标和无图标样式。各圈及中心当前目录名称均使用同一字号、字重，不随空间或悬停缩小、放大。
- 短名称按实际文字居中；长名称最多两行，空间不足时省略，两行长名保留首尾。角落窄扇区先利用外侧空间，不通过缩小字体塞入名称。
- 名称被省略时，停留约 550 毫秒会浮现完整名称和路径。移到其他目录、蓝弧、滚轮切换或关闭时自动收起。
- 悬停中心圆可以查看完整目标路径及待移动文件名，不再占用常驻侧栏空间。
- 没有子目录的文件夹不显示蓝弧，可直接点击扇区作为移动目标。

滚轮与键盘
- 同级目录超过四个时，滚轮仅切换鼠标所在圈的目录，不会转去滚动另一圈。
- 快速滚动会连续衔接过渡；目录读取完成后会在合适的过渡边界显示，不再打断滚动动画。动画期间名称保持正向，排版不反复变化；完整圆环的新旧名称随转动平滑交接。
- 前两圈滚轮停下约 850 毫秒后继续展开；第三圈仍须移出蓝弧再移回。
- 方向键选择目录或圈层，Enter / 空格进入目录；Ctrl + Enter 将文件移动到键盘选中的目录。
- Home 将焦点移回中心；在中心按 Enter 确认移动。长按 Enter 不会连续进入。
- Ctrl + 左键点击目标扇区或中心，可在该位置新建子文件夹。创建后不会自动移动文件，需再确认。

新手引导与安全演示
- 托盘的“新手引导”或轮盘中的 F1 均可重新打开教程。
- 引导第二页用指针动画演示“停留辨认 → 移向蓝弧 → 进入后稍移出蓝弧再返回”。
- 托盘“安全演示”不会移动或创建真实文件，适合先熟悉蓝弧手势。
- 保持原有蓝灰配色；打开分圈舒展、扇区高亮过渡、蓝弧呼吸、进退内容交接、托盘/按钮/提示均有动效。新手引导同步采用纯文字目录。
- 关闭 Windows“辅助功能 → 视觉效果 → 动画效果”时，程序使用静态反馈，手势和触发时长不变。

安装与设置
- 安装程序：下载“LingRing-0.6.4-windows-x64-setup.exe”。支持当前用户安装、桌面快捷方式和可选开机自启。
- 便携版：完整解压后直接运行。便携版的设置也保存在当前用户数据目录，不写进程序目录。
- 本版未做代码签名。安装和便携两种入口使用同一份已验证程序，下载页提供 SHA-256 校验值。程序无需激活码。
- 托盘中可更改轮盘默认起点、刷新缓存、重置常用排序、设置成功提示、暂停监听或退出。
- “此电脑 → 本地磁盘 → 文件夹”是统一层级；默认起点不会限制导航范围，右键可一直返回磁盘层。
- 目录按需异步读取，不依赖 Everything、Listary 或 Windows Search；只列已就绪的本地固定盘和可移动盘。
- 若使用 Listary，请关闭其 Desktop / File Explorer 鼠标中键菜单，避免重复响应。
- 设置与排序默认位于 %LocalAppData%\GongSiOrganizer.RadialPrototype。卸载不会删除用户归档文件或这份设置。

移动规则
- 左键直接移动，不保留副本，不弹第二次确认，也不进入资源管理器撤销队列。首次体验可使用测试文件或安全演示。
- 文件重名时自动生成可用名称，不覆盖原文件；禁止把文件夹移到自身或其子目录。
- 确认目标后轮盘向圆心收拢，原位置显示等待或真实移动结果；蓝色等待、绿色全部完成、黄色部分完成、红色移动失败。快速完成直接显示勾号，部分完成/失败显示数量并提示原因。
- 托盘“桌面成功通知”可额外显示目标路径；原位置结果反馈可穿透点击，再次打开轮盘会清除旧反馈。
- 跨磁盘移动较大目录需要等待；处理中会阻止从托盘退出。
- 程序不上传文件名或目录，不接入联网分类。

可选启动参数（普通使用无需填写）
--root "目录"       本次临时指定默认起点，仍可返回“此电脑”
--root shell:ThisPC  本次从“此电脑”打开
--demo              显示安全演示，可与正常实例并行，演示实例不注册全局监听
--demo-corner       在屏幕左上角验证各圈边界自适应布局
--demo-position    配合 --demo 使用；center、left、right、top、bottom 或 top-left 等四角位置
--demo-onboarding   显示新手引导预览
--no-listener       不注册中键监听
