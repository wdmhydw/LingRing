文件快速归档 0.5.5

0.5.5：目录统一为“此电脑 → 本地磁盘 → 文件夹”的包含关系。第一圈显示当前已就绪的本地固定盘和可移动盘，可在不同磁盘间逐层选择目标并直接移动；任意文件夹都可以作为轮盘默认起点，右键仍能继续退回父目录、磁盘和“此电脑”。目录采用异步按需读取，不会在启动时扫描所有磁盘；磁盘访问不占用界面线程，最多两路并发，并根据系统内存使用约 4–24 MB 的 LRU 缓存。旧版固定根目录和常用排序会自动迁移。补全真实跨盘单文件及含空子目录文件夹的移动回退与验证。滚轮只切换当前圈的同级预览，普通悬停约 450 毫秒、滚轮停止约 850 毫秒后才进入下一级。悬停高亮不再移动扇区，只有真正展开下级目录时播放轮盘缩放动画。

0.5.4：关闭轮盘控件在获得键盘焦点时由 WPF 自动绘制的黑色虚线提示框，同时保留 Esc、Backspace 等键盘操作。GitHub 项目页新增真实界面使用图片。

0.5.3：首次启动时若尚无有效归档目录，不再额外弹出独立的系统文件夹选择窗口，而是直接进入新手引导，并在最后一步要求设置有效的目标归档文件夹。全局中键监听增加窗口范围判断：只有鼠标位于 Windows 桌面或文件资源管理器的文件列表区域时才会响应；浏览器、聊天软件、Codex、任务栏、资源管理器工具栏及其他软件中的系统文件选择框均不会弹出轮盘。

0.5.2：针对 125%/150% 等高 DPI 缩放下托盘菜单文字发灰、发糊的问题，菜单不再使用透明分层窗口，改由 Windows 11 DWM 提供原生圆角；同时启用像素对齐、ClearType、Display 排字和更清晰的整数字号。打开动画结束后会彻底移除临时位移，不再让文字长期停留在变换渲染层中。菜单视觉尺寸基本不变。

0.5.1：新手引导最后一步新增“目标归档文件夹”设置，可直接选择位置；程序会先读取新目录，成功后才切换，取消或失败会保留原设置。引导示意圆环改为更浅的蓝色。托盘菜单改用当前鼠标的真实屏幕坐标，显示在托盘图标旁边；同时缩小整体尺寸，并为阴影预留边距以修复右侧圆角裁切。

0.5.0：软件正式更名为“文件快速归档”。应用图标去除多余透明边距，在系统托盘中显示得更大、更清楚；右键托盘菜单改为与轮盘一致的蓝灰配色、圆角、阴影和缓动界面。首次启动会显示四步新手引导，也可随时从托盘重新打开。新增 Windows 安装程序，可选择创建桌面快捷方式以及是否开机自动启动。

0.4.1：采用“方案 3 · 扇区文件夹”作为正式应用图标。图标内置 16、20、24、32、40、48、64、96、128 和 256 像素尺寸，并同时用于 EXE、系统托盘和桌面快捷方式。

0.4.0：归档根目录不再固定为 E:\GongSi。右击托盘图标可以看到当前根目录，并通过“更改归档根目录…”随时选择其他文件夹；程序会先完整读取新目录，成功后才切换，读取失败时仍保留原目录。选择结果会自动保存供下次启动使用。常用目录频次按根目录分别记录，切换后不会混用。

0.3.1：轮盘显示时，左键点击扇区和中心圆以外的透明空白，或点击轮盘窗口之外，都会立即关闭轮盘。在任意目标目录扇区上按 Ctrl + 鼠标左键（也支持当前目标中心圆），会弹出命名窗口并在该目录下新建子文件夹；创建后新文件夹自动成为当前目标，但不会自动移动文件，需再用普通左键确认。

0.3.0：移动成功默认静默，不再进入 Windows 通知中心。移动失败、目录刷新等需要关注的信息改用更小、无声音、自动淡出的悬浮提示；可在托盘菜单勾选“显示移动成功提示”。程序会在每次确实移动了文件后记录一次目标选择，并在每一级目录中优先展示更常用的同级文件夹；可从托盘重置排序。中心圆文字和底部操作提示也已向内收拢。

0.2.1：支持桌面和文件资源管理器的多选批量移动。中键点在当前选择集中的任意项目上，会把整个选择集交给轮盘；中键点在未选中的其他项目上时，只处理鼠标下的项目，避免误带旧选择。

0.2.0：正式接入直接移动。对真实文件或文件夹打开轮盘后，左键确认会立即将它移动到选中的归档根目录子目录；不再只是预览目标。

使用方法
1. 请在 Listary 的“选项 → 集成”中关闭 Desktop 和 File Explorer 的鼠标中键菜单，避免两个程序同时响应中键。
2. 安装后启动“文件快速归档”。首次启动会显示新手引导；最后一步可以保留最高层“此电脑”，也可以向下选择常用文件夹作为轮盘默认起点。关闭引导后程序常驻系统托盘。
3. 在桌面或文件资源管理器文件区域的普通文件或文件夹上单击鼠标中键。已经框选或多选时，请在其中任意一个已选项目上单击中键。其他软件、任务栏及资源管理器工具栏中的中键操作不会触发本程序。
4. 鼠标移入扇区并停稳约 450 毫秒会展开下一层；同级目录超过 4 个时，用滚轮循环切换。滚轮停止约 850 毫秒后才继续进入下一级，连续滚动会重新计时。
5. 选错时，单击鼠标右键或按 Backspace 返回上一级；按 Esc 取消。
6. 需要临时建立目标子目录时，把鼠标放在父目录扇区上，按住 Ctrl 再单击左键；输入名称并按 Enter 创建。新目录会成为当前目标，再用普通左键确认移动。Ctrl + 左键中心圆时，会在中心当前显示的目标下创建。
7. 左键单击目标扇区或中心圆确认。中心会显示待移动项目数量；确认后立即批量移动。成功时默认不打扰，失败或部分失败时会显示精简提示。
8. 左键点击轮盘透明空白或轮盘以外区域会直接关闭；如果中键点到桌面空白处，则只显示“请在文件或文件夹上点击鼠标中键”，再次点击即可关闭。
9. 右击托盘图标可查看或更改轮盘默认起点、重新打开新手引导、显示安全演示、刷新目录缓存、重置常用排序、选择是否显示成功提示、暂停监听或退出。

安装与开机自启
- 运行“文件快速归档-0.5.5-安装程序.exe”，按向导完成安装。
- 安装选项中可勾选“创建桌面快捷方式”和“开机时自动启动文件快速归档”；开机自启默认不强制开启。
- 卸载程序会删除安装目录及其创建的快捷方式，不会主动删除你的归档文件，也不会删除已经移动到归档目录中的内容。

设置轮盘默认起点
- 右击系统托盘中的程序图标并选择“更改”，最上层是“此电脑”，其下依次是本地磁盘和文件夹，不再是两个并列模式。
- 选择“此电脑”时轮盘从磁盘入口开始；选择某个文件夹时会默认直接展开到该处，但右键可以继续退回它的父目录、磁盘和“此电脑”。
- 目录轮盘只列出当前已就绪的本地固定盘和可移动盘，不包含网络映射盘；目录只在悬停或恢复默认起点时读取下一级。
- 程序会先验证所选文件夹能够从“此电脑”逐级到达，成功后才正式切换，因此无权限、隐藏、系统或联接目录不会破坏原来的设置。
- 目录读取不依赖 Everything、Listary 或 Windows Search；慢速磁盘不会占用界面线程。
- 设置会优先保存在当前用户的 LocalAppData\GongSiOrganizer.RadialPrototype\settings.json；该位置不可写时会自动换到其他可写位置。
- 启动参数 --root 会在该次启动中优先于已保存设置；传入本地文件夹时，它会成为“此电脑”下的临时默认起点。

常用目录排序
- 一次批量移动只记作一次选择，不会因选中文件多而增加权重。
- 选择深层目录时，它沿途所属的公司、项目和子目录都会各累计一次，因此每一圈都能独立体现常用顺序。
- 只保存目标目录的相对路径、次数和最近使用时间，不保存被移动文件的名称。
- 记录文件会优先保存在当前用户的 LocalAppData\GongSiOrganizer.RadialPrototype；它与旧版曾出现权限问题的 GongSiOrganizer 目录完全隔离。首选位置不可写时会自动换到可写位置，记录损坏或保存失败都不会阻止移动。

移动规则
- 只执行移动，不保留一份副本。
- 目标只能位于当前已就绪的本地固定盘或可移动盘；默认起点不是限制边界，可以右键返回上级并选择其他磁盘。
- 遇到同名文件或文件夹时不会覆盖，会自动使用“名称 (1)”这样的可用名称。
- 禁止把文件夹移动到它自己或它的子目录。
- 新建子文件夹只能发生在轮盘当前选中的真实目录内；空名称、路径分隔符、Windows 保留名称和已存在的同名项目都会被阻止，并在命名窗口内提示修改。
- 文件不存在、目标失效、文件被占用或权限不足时不会强行操作，会显示精简的失败原因。
- 移动文件夹期间会阻止从托盘退出，避免人为中断操作。
- “在鼠标位置显示安全演示”永远不会移动文件。

注意
- 左键确认后没有第二次确认窗口，也不会进入资源管理器的撤销队列；请先确认中心显示的目标文件夹。
- 跨磁盘移动大文件夹可能需要较长时间；移动期间托盘图标说明会显示正在处理，完成后恢复。
- 不要重新启用此前的资源管理器右键 Shell 扩展。

可选启动参数
--root "目录"       本次启动临时把该目录设为轮盘默认起点（仍可返回“此电脑”）
--root shell:ThisPC 本次启动临时从“此电脑”最高层打开轮盘
--demo              在屏幕中间显示安全演示
--demo-corner       在屏幕左上角显示四分之一圆安全演示
--demo-invalid      显示无效目标提示圆
--no-listener       不注册中键监听
